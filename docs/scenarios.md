# 시나리오 케이스

- **프로젝트**: Civil War — 오버워치 디스코드 채널별 내전 운영 웹앱
- **버전**: v1
- **연관 문서**: `docs/requirements.md`, `docs/workflow.md`, `docs/erd.md`
- **표기**: 시나리오 ID `SC-XX`, 연관 기능 `F#`. 형식은 Given(전제) / When(행위) / Then(결과)

---

## 0. 액터

| 액터 | 설명 |
|---|---|
| **슈퍼관리자** | 채널·관리자 계정 발급 (DB 또는 콘솔) |
| **채널 관리자** | 본인 채널 운영 (멤버·내전·결과). 예: 벙커, 옵무원 |
| **참가자(멤버)** | 시스템 로그인 없음. 관리자가 대신 등록·운영 |

---

## 1. 계정 · 채널 (SC-01~03)

### SC-01 · 채널 및 관리자 계정 발급

- **Actor**: 슈퍼관리자 / **연관**: F1
- **Given** 새 디스코드 채널 운영자가 합류함
- **When** 슈퍼관리자가 `channels` 레코드와 `admins` 계정(username/비번/내부 이메일)을 발급하고 `owner_admin_id`로 연결
- **Then** 해당 관리자가 자기 채널에 로그인할 수 있고, 다른 채널 데이터는 보이지 않음

### SC-02 · 관리자 로그인 (정상)

- **Actor**: 채널 관리자 / **연관**: F2
- **Given** 발급된 아이디·비밀번호 보유
- **When** 로그인 화면에 아이디+비번 입력
- **Then** 서버가 `username→내부 이메일` 변환 후 인증 성공, 본인 채널 대시보드로 이동

### SC-03 · 로그인 실패

- **Actor**: 채널 관리자 / **연관**: F2
- **When** 잘못된 아이디 또는 비번 입력
- **Then** "아이디 또는 비밀번호가 올바르지 않습니다" 표시, 진입 차단
- **대안** 소유 채널이 없는 계정 → 로그인은 되나 "배정된 채널 없음, 슈퍼관리자 문의" 안내

## 2. 멤버 관리 (SC-10~14)

### SC-10 · 신규 멤버 등록

- **Actor**: 채널 관리자 / **연관**: F3, F4
- **Given** 대시보드 > 멤버 관리 진입
- **When** 배틀태그·디스코드 이름, 역할별 티어(탱/딜/힐), 주/부 포지션, 선호 영웅(최대 5), 선호 맵 입력 후 저장
- **Then** `members`(신규) + `channel_members` + `member_role_ratings`/`member_hero_preferences`/`member_map_preferences` 생성

### SC-11 · 이미 다른 채널에 있는 배틀태그 등록

- **Actor**: 채널 관리자 / **연관**: F3
- **Given** 등록하려는 배틀태그가 이미 다른 채널에서 글로벌 등록됨
- **When** 관리자가 그 배틀태그로 신규 등록 시도 (관리자는 이를 모름)
- **Then** UI는 신규 등록처럼 동작, 서버가 기존 `members.id`를 재사용해 현재 채널에만 매핑·프로필 생성. 다른 채널 프로필은 영향 없음

### SC-12 · 티어 일부만 입력 (한 포지션만 함)

- **Actor**: 채널 관리자 / **연관**: F4
- **Given** "힐만 하는" 멤버
- **When** 힐러 티어만 입력, 탱/딜 미입력
- **Then** `member_role_ratings`에 support 행만 생성. 탱/딜은 **배정 불가**로 표시 (팀 빌딩에서 해당 포지션 배정 안 됨)

### SC-13 · 멤버 정보 수정

- **Actor**: 채널 관리자 / **연관**: F4
- **When** 시즌이 바뀌어 티어 갱신 입력
- **Then** 해당 채널의 `member_role_ratings.rating_score` 재계산·저장. 다른 채널 동일 멤버 프로필은 불변

### SC-14 · 멤버 삭제

- **Actor**: 채널 관리자 / **연관**: F3
- **When** 채널에서 멤버 제외
- **Then** `channel_members` 및 채널별 프로필 제거. **과거 매치 기록(`team_members`)은 보존**(FK RESTRICT). `members` 글로벌 행은 다른 채널에서 쓰이면 유지

## 3. 내전 진행 — 정상 흐름 (SC-20~26)

### SC-20 · 참가자 10명 선택

- **Actor**: 채널 관리자 / **연관**: F5
- **Given** 대시보드 > 내전 시작
- **When** 채널 멤버 중 10명 체크
- **Then** 10명 충족 시 "팀 빌딩" 활성화. 9명/11명이면 진행 불가

### SC-21 · 기본 모드(자동 밸런스) 팀 생성

- **Actor**: 채널 관리자 / **연관**: F8
- **Given** 참가자 10명 확정, 모드=기본
- **When** "팀 생성" 실행
- **Then** 역할 슬롯(1-2-2) 만족하는 5+5 조합 중 점수차 최소 상위 10개에서 랜덤 1개 선택 → 팀 확정 화면

### SC-22 · 팀장 모드(최고티어) + 드래프트

- **Actor**: 채널 관리자 / **연관**: F6, F7
- **Given** 모드=팀장(최고티어)
- **When** 점수 상위 2명이 팀장으로 자동 배치 → **각 팀장이 자기 포지션 먼저 지정** → 남은 8명을 8픽 스네이크 드래프트(1-2-2-2-1), 각 픽마다 포지션 지정
- **Then** 픽마다 양 팀 점수 실시간 갱신(증가 초록/감소 빨강), 8픽 완료 시 5:5 완성

### SC-23 · 팀장 직접 지정 모드

- **Actor**: 채널 관리자 / **연관**: F6
- **When** 모드=팀장(직접), 관리자가 팀장 2명 수동 선택
- **Then** 선택된 2명이 각 팀에 배치 후 SC-22와 동일하게 드래프트 진행

### SC-24 · 맵 자동 선정

- **Actor**: (자동) / **연관**: F9
- **Given** 팀 확정 완료
- **When** 맵 선정 단계 진입
- **Then** 참가자 10명의 선호 맵 **합집합**에서 1개 랜덤 선택, 그 맵을 선호한 멤버 목록 함께 표시

### SC-25 · 영웅 밴

- **Actor**: 채널 관리자 / **연관**: F10
- **When** A팀 밴 1명 → B팀 밴 1명 선택
- **Then** `matches.banned_hero_a/b` 저장. 최종 내전 정보(구성·포지션·점수·맵·밴) 화면 표시

### SC-26 · 결과 입력

- **Actor**: 채널 관리자 / **연관**: F11
- **Given** 내전(오프라인 게임) 종료
- **When** 승팀·스코어(필수) 입력, 사용 영웅(선택, 이름 자동완성)·메모(선택) 입력 후 저장
- **Then** 단일 트랜잭션으로 `matches`(승팀/스코어/메모) + `team_members.hero_used`(입력분) + `teams.is_winner`×2 저장
- **대안** 영웅 미입력 → 해당 칸은 NULL, 통계에서 "미기록"

---

### SC-27 · 팀 구성 디스코드 공유

- **Actor**: 채널 관리자 / **연관**: F12b
- **Given** 팀 확정([7]) 또는 최종 정보([10]) 화면
- **When** "디스코드 복사" 버튼 클릭
- **Then** 팀/포지션/맵/밴이 정리된 텍스트가 클립보드에 복사됨 → 관리자가 디스코드에 붙여넣기 또는 화면 공유로 참가자에게 전달

### SC-28 · 매치 결과 수정

- **Actor**: 채널 관리자 / **연관**: F12c
- **Given** 승팀을 반대로 입력한 매치 발견
- **When** 전적 화면 > 해당 매치 > 수정 > 승팀·스코어 정정 후 저장
- **Then** `matches`/`team_members` UPDATE, `teams.is_winner` 재산정. 통계 즉시 반영

### SC-29 · 매치 삭제

- **Actor**: 채널 관리자 / **연관**: F12c
- **When** 잘못 생성된 매치를 삭제 (확인 다이얼로그)
- **Then** `teams`/`team_members` CASCADE 제거. 본인 채널 매치만 가능

## 4. 다음 판 분기 (SC-30~33)

### SC-30 · 같은 팀으로 한 판 더

- **Actor**: 채널 관리자 / **연관**: F11, Q5
- **Given** 결과 저장 완료
- **When** "같은 팀으로 한 판 더" 선택
- **Then** 현재 A/B 구성·배정 포지션 복사해 새 `matches` 생성 → 맵 재추첨 + 밴부터 다시(SC-24)

### SC-31 · 맵만 바꾸기

- **When** "맵만 바꾸기" 선택
- **Then** 팀 고정, 새 맵 선정 + 밴 (SC-30과 동일 핸들러, 라벨만 다름)

### SC-32 · 처음부터 재편성

- **When** "처음부터 재편성" 선택
- **Then** 참가자 선택(SC-20)부터 다시. 멤버 교체·인원 변경 가능

### SC-33 · 세션 종료

- **When** "세션 종료" 선택
- **Then** 워크플로우 종료, 채널 대시보드로 복귀

## 5. 통계 조회 (SC-40~41)

### SC-40 · 개인 전적 조회

- **Actor**: 채널 관리자 / **연관**: F12
- **When** 전적·통계 > 특정 멤버 선택
- **Then** 해당 채널에서의 판별 사용 영웅·같은 팀 멤버·승패를 `team_members` JOIN으로 집계 표시

### SC-41 · 채널 전적 / 날짜별 세션

- **Actor**: 채널 관리자 / **연관**: F12
- **When** 전적·통계 진입
- **Then** `matches`를 `played_at::date`로 그루핑해 "5/30 금요일: 5판, A승 3" 식 세션 요약 표시

## 6. 예외 · 엣지 케이스 (SC-50~56)

### SC-50 · 자동 밸런스 조합 불가

- **연관**: F8
- **Given** 탱커 가능자가 1명뿐이라 1탱-2딜-2힐 양 팀 구성 불가
- **When** 기본 모드로 팀 생성 시도
- **Then** "유효한 조합 없음" 경고 + 팀장 직접 지정 모드 권유

### SC-51 · 드래프트 중 배정 불가 포지션 지정

- **연관**: F7
- **When** 팀장이 티어 없는 포지션 슬롯에 멤버를 드롭
- **Then** 드롭 거부(빨간 표시) + 경고. 티어 있는 포지션만 허용

### SC-52 · 결과 입력 중 이탈

- **연관**: F11
- **Given** 팀 확정([7])은 이미 DB 저장됨
- **When** 결과 입력 전 새로고침/이탈
- **Then** 매치는 "결과 미입력" 상태로 보존, 나중에 이어서 입력 가능

### SC-53 · 무승부 처리

- **연관**: F11
- **When** 승팀 없이 무승부로 저장
- **Then** `matches.winner_side` NULL, 양 팀 `is_winner=false`

### SC-54 · 세션 중 멤버 이탈

- **When** 한 명이 중간에 빠짐
- **Then** "처음부터 재편성"으로 9명+교체 1명 재선택

### SC-55 · 선호 맵이 아무도 없음

- **연관**: F9
- **Given** 참가자 전원 선호 맵 미입력
- **When** 맵 선정 단계
- **Then** 전체 맵 풀에서 랜덤 선택 (fallback)

### SC-56 · 채널 격리 침범 시도

- **연관**: 보안/RLS
- **When** 관리자 A가 URL 조작으로 채널 B의 매치/멤버에 접근 시도
- **Then** RLS + Server Action 채널 컨텍스트 검증으로 차단 (빈 결과 또는 403)
