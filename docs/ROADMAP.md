- 기본 페이지: 랜딩 / 로그인(아이디·이메일) / 대시보드 메뉴 허브

- ✅ 관리자 계정 생성 + 로그인 동작
- ✅ 채널 시드 (슈퍼관리자 승격 + 첫 채널)

## Phase 3 — 멤버 관리 ✅  (F3·F4)

- ✅ 입력 폼: 배틀태그, 디코명, 역할별 티어, 주/부 포지션, 선호 영웅, 선호 맵

- 🔶 남은 확인: 채널 시드 후 브라우저에서 실제 CRUD 동작 검증

## Phase 4 — 내전 워크플로우 ✅  (F5~F11)

`spec/workflow.md` [3]~[12] 를 화면으로:

- ✅ [3] 참가자 10명 선택
- ✅ [4] 모드 선택 (기본 ✅ / 팀장 4모드 ⬜ 비활성)
- ✅ [4] 모드 선택 — 기본 / 팀장-최고티어 / 팀장-직접지정 (탱커·예능 모드는 미구현)
- ✅ [5-A] 자동 밸런스(미러제거 126분할 + 슬롯배치 최적화 + 점수차 최소 상위10 랜덤) — `src/domain/team-builder.ts`, 단위테스트 통과
- ✅ [5-B][6] 팀장 확정 + 스네이크 드래프트 — `src/domain/draft.ts`(순서·슬롯·자격·팀장선정, 단위테스트 9개). **클릭 기반**(드래그앤드롭 아님), 팀장 포지션 선지정 → 1-2-2-2-1 스네이크, 실시간 점수, 직전 픽 취소. captain_id·pick_order 저장.
- ✅ [7] 팀 확정(`createMatch`) + **디스코드 복사**(F12b, `src/domain/discord.ts`)
- ✅ [8] 맵 자동 선정 (선호 합집합 랜덤, SC-55 fallback)
- ✅ [9] 영웅 밴 (팀당 1명, 자동완성)
- ✅ [11] 결과 입력 (승팀·스코어 필수, 영웅 자동완성 선택)
- ✅ [12] 다음 판 분기 (4버튼)

> 남은 것: 팀장 탱커/예능 모드(쉬움), dnd-kit 드래그 전환(폴리싱), 실시간 점수 카운트업 모션. 핵심 플로우는 빌드·테스트 통과, 브라우저 검증 대기.
