# 새 채널(서버) 연결 가이드

새 디스코드 서버에서 `/내전` 봇을 쓰려면 **그 서버(길드)를 웹의 채널에 연결**해야 한다.
연결은 그 서버의 **서버 ID(길드 ID)** 를 받아 `channels.discord_guild_id` 에 매핑하는 작업.

> 배경: 런타임은 `interaction.guild_id → channels.discord_guild_id` 로 어느 채널에
> 등록할지 정한다. 이 매핑이 없으면 그 서버에서 `/내전`·`/내전-프로필` 이 동작하지 않는다.
> 관련 코드: [`src/lib/discord/register.ts`](../../src/lib/discord/register.ts) (`resolveChannelId`)

연결 전 준비:
- 슬래시 커맨드는 **글로벌 등록**되어 봇이 초대된 모든 서버에 자동 노출 (반영 ~1시간).
  → 새 서버엔 **봇 초대**만 하면 커맨드가 보인다. 등록 스크립트 재실행 불필요.
- 봇 초대 OAuth 권한: `bot` + `applications.commands`

**봇 초대 링크 (모든 서버 공용, 권한은 [discord-bot-setup.md](discord-bot-setup.md) §6 기준):**

```
https://discord.com/oauth2/authorize?client_id=1512838267962261655&scope=bot+applications.commands&permissions=16862272
```

> 이 링크로 접속 → 연결할 서버 선택 → 승인. 채널 관리자에게 이 링크를 같이 보내
> 봇을 먼저 초대하게 해도 된다. (서버 "관리자" 권한을 가진 사람만 초대 가능)

---

## A. 채널 관리자에게 보낼 안내문 (복붙용)

> **[내전 봇 연결 — 서버 ID 알려주세요]**
>
> 디스코드 내전 봇을 이 서버에 연결하려고 합니다. 아래대로 **서버 ID** 를 복사해서 보내주세요.
>
> **1단계 — 개발자 모드 켜기 (※ 서버 설정이 아니라 "사용자 설정"입니다)**
> - PC: 화면 **좌측 맨 아래, 내 아바타 옆 톱니바퀴(⚙ 사용자 설정)** 클릭 → 왼쪽 메뉴에서
>   **앱 설정 > 고급** → **개발자 모드** 토글 **켜기**
>   - ⚠️ 서버 이름 클릭해서 나오는 "서버 설정"이 아닙니다. **내 계정 설정(톱니바퀴)** 입니다.
> - 모바일: 우측 하단 **내 프로필** → **앱 설정 > 고급** → **개발자 모드** 켜기
>
> **2단계 — 서버 ID 복사 (이건 그 서버에서)**
> - PC: 화면 **왼쪽 서버 아이콘 목록**에서 해당 서버 아이콘 **우클릭** → **서버 ID 복사하기**
> - 모바일: 서버 이름 **길게 누르기** → **서버 ID 복사하기**
>
> **3단계 —** 복사된 **숫자(18~19자리)** 를 저에게 보내주세요. (예: `1460661490485821484`)
>
> 그리고 봇이 아직 이 서버에 없다면, 제가 드리는 **초대 링크**로 봇을 먼저 추가해주세요.
>
> ※ 서버 ID는 비밀번호가 아니라 단순 식별자라 공유해도 안전합니다.

> 💡 헷갈림 주의: **"서버 설정"**(서버 이름 클릭)과 **"사용자 설정"**(좌측 하단 톱니바퀴)은
> 다른 메뉴입니다. **개발자 모드 토글은 "사용자 설정 > 고급"** 에만 있습니다. 토글을 켠 뒤에야
> 서버 아이콘 우클릭 메뉴에 "서버 ID 복사하기"가 나타납니다.

> 🔁 개발자 모드 켜기 싫으면 — **채널 링크로도 가능**:
> 아무 채널 **우클릭 → 링크 복사** → 나온 주소
> `https://discord.com/channels/`**`<서버ID>`**`/<채널ID>` 에서 **첫 번째 숫자**가 서버 ID.
> (웹 디스코드면 주소창에 그대로 보임)

---

## B. 운영자(연결 담당) 작업

받은 서버 ID로 해당 채널 행에 매핑한다.

1. 웹에서 그 채널이 이미 있는지 확인. 없으면 **채널을 먼저 생성**(슈퍼관리자).
2. `channels.discord_guild_id` 를 받은 서버 ID로 설정.
   - 임시 방법(SQL): Supabase SQL Editor 에서
     ```sql
     update public.channels
        set discord_guild_id = '<받은 서버 ID>'
      where name = '<채널 이름>';
     ```
   - ⚠️ `discord_guild_id` 는 **unique** — 한 서버는 한 채널에만 연결된다.
3. 그 서버에서 `/내전-프로필` 실행 → "채널 연결됨" 동작하면 성공.

> TODO(개선): 웹 관리자 화면에 "디스코드 서버 ID" 입력칸을 추가하면 SQL 없이 셀프 연결 가능.
> 그 전까진 운영자가 위 SQL 로 수동 매핑.

## 트러블슈팅

| 증상 | 원인 / 조치 |
|---|---|
| 새 서버에 `/내전` 이 안 보임 | 봇 미초대 → 초대. 또는 글로벌 등록 전파 대기(~1시간), 디스코드 **Ctrl+R** |
| `/내전-프로필` 이 "채널과 연결되지 않았어요" | `channels.discord_guild_id` 미설정 → B 작업 수행 |
| 서버 ID 복사 메뉴가 없음 | 개발자 모드 OFF → A-1 켜기 |
| 다른 채널에 잘못 연결됨 | `discord_guild_id` 가 unique. 잘못된 행에서 지우고 올바른 행에 설정 |
