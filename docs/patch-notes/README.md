# 패치노트 아카이브

발행한 패치노트를 **차곡차곡 보관**하는 곳 (복사 원본 + git 이력용).

- **라이브 게시판은 DB**다: 작성 `/app/patch-notes` → 표시 `/patch` + 디스코드 `/패치노트`(최신 1건).
- **이 폴더의 파일은 사본/이력**이다 — 앱이 읽지 않는다. 새 글을 올릴 때 여기서 복사해 폼에 붙여넣으면 편하다.

## 규칙

- 파일명: `YYYY-MM-DD-slug.md` (날짜 접두 → 최신이 위로 정렬).
- 프론트매터 `title` = 폼의 **제목** 칸.
- `---` 아래 본문 = 폼의 **본문** 칸 (그대로 복사·붙여넣기).
- 출처는 **Blizzard 공식 + 나무늘보** 두 곳만.

## 작성 흐름

1. 제미나이로 나무늘보 영상 요약 → 텍스트 확보
2. `/patch-note` 스킬 실행 → 정합·첨삭 후 **이 폴더에 새 파일 생성** + 복붙 블록 출력
3. `/app/patch-notes` 폼에 제목·본문 붙여넣고 게시
