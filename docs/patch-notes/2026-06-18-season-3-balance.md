🎮 오버워치 공식 패치

• 🦹 신규 영웅 시온 — 쌍권총 딜러, 오토바이 궁극기(마우스로 정교하게 조종)…숙련도형이지만 화력 강함

• 🛡️ 탱커 ↑ — 자리아 방벽 패치 + 라인하르트 돌진 데미지·속도 상향으로 '뚜벅이' 탱커 입지 상승

• 🗡️ 겐지 ↑ — 튕겨내기 쿨다운 2초 감소 + 명상 회복량 30→50, 교전 유지력 강화

• ❄️ 메이 ↑ — 주무기 사거리 10→12m (사실상 약 20% 상향)

• 💉 힐러 ↑ — 일리아리(스킬 후 딜레이 감소) · 미즈키(분신술 쿨다운·지속 조정)

• 🦊 키리코 ↓ — 유도 부적 사거리 감소

• 🤖 부산 메카 기지에 디몬 자리 비어 있음 — 다음 시즌 신규 메카 떡밥

• ✨ 신규 스킨 — '초월(울트라)' 스킨(전용 인게임 효과·사운드) + 여름 해변 테마

🛠️ 내전 웹·봇 업데이트

• 📜 채널별 **내전 규칙** 추가 — 채널 관리자가 규칙을 직접 작성/편집(기본 템플릿 제공), 참가자는 대시보드·결과·최종 대진표 화면의 "규칙" 버튼으로 확인

• 📺 라이브용 — 규칙 버튼을 상단에 상시 노출 + 큰 글씨 모달(방송 화면에서 보기 편하게)
